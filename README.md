# Financial Dashboard UI

A financial data dashboard built with React and JavaScript that fetches and displays real-time market data.

## Why I Built This

This was my first major project — I wanted to build something that pulled live data from an external API and displayed it in a clean, readable interface. After completing it, I rebuilt it from scratch as financialui2 to improve the structure and apply what I had learned. Building it twice was intentional.

## Tech Stack

- React
- JavaScript
- HTML
- CSS

## Run Locally

```bash
npm install
npm start
